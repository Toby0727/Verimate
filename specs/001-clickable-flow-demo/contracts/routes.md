# UI Contract: 页面与路由

所有路径均为英文，界面文案也是英文（FR-011）。"访问"一列说明的是谁能看到这个页面；不满足时的处理写在"不满足时"一列。所有守卫都只在浏览器端按当前示例身份判断，**仅用于演示，不构成安全边界**。

## 公共页面

| 路由 | 内容 | 访问 |
| --- | --- | --- |
| `/` | 落地页：介绍 Verimate，提供"Sign in with Google (Sample)"按钮，以及进入访客预览的入口 | 所有人 |
| `/about-demo` | 逐条列出每条流程是"Sample"还是"Live"（FR-007） | 所有人 |
| `/terms`、`/privacy` | 示例草稿，标注为 Sample（FR-049） | 所有人 |
| `/sign-in` | 示例 Google 登录：选择"新用户"开始入驻，或直接选择一个示例身份 | 未登录 |

## 入驻：`app/(onboarding)/`

| 路由 | 内容 | 不满足时 |
| --- | --- | --- |
| `/onboarding/birthday` | 填写生日 | 未满 18 岁时，只能去已录取新生路径，否则被拦下 |
| `/onboarding/path` | 选择"在校生"或"已录取新生" | |
| `/onboarding/verify` | 输入学校邮箱，填写示例验证码（界面直接显示验证码） | 拒绝非学校邮箱和已被绑定的学校邮箱 |
| `/onboarding/admitted` | 上传录取材料（示例：只记录文件名） | 完成后状态为"审核中"，仍可继续填资料 |
| `/onboarding/profile` | 必填资料表单，选填项可以先跳过 | 缺必填项时不能提交，并逐项提示 |

## 主应用：`app/(app)/`，底部 5 个标签

| 路由 | 标签 | 内容 |
| --- | --- | --- |
| `/roommates` | Roommates | 列表和筛选：预算、日期、区域、性别、生活习惯、同楼。访客看到模糊卡片 |
| `/roommates/[id]` | | 资料详情：验证状态、注册时间、模糊的匹配度区域、发送消息请求、举报、拉黑 |
| `/for-you` | For You | 匹配人数、模糊卡片（分数和一句话理由）、解锁（剩余次数）；会员看到全部内容 |
| `/sublets` | Sublets | 列表和筛选：区域、价格、日期、房型、是否带家具 |
| `/sublets/[id]` | | 详情：建立联系前只显示大致区域；联系发帖人、举报 |
| `/sublets/new` | | 发帖表单：必填项、示例照片、声明勾选、可选租约 |
| `/messages` | Messages | 分为三个区：Requests（收到的请求）、Sent（发出的请求）、Chats（聊天） |
| `/messages/requests/[id]` | | 单条请求：接受、删除、拉黑 |
| `/messages/[id]` | | 聊天：首次进入时的付款提醒、防骗提醒 |
| `/me` | Me | 我的：验证状态、会员权益、"正在找 / 暂停"、各项设置入口、谁看过我（会员） |
| `/me/profile` | | 编辑资料（必填和选填） |
| `/me/questionnaire` | | 详细问卷，以及"允许用于 AI 匹配"的同意选项 |
| `/me/sublets` | | 我的帖子：标记已转出、确认是否还有效、查看租约状态 |
| `/me/membership` | | 会员页：权益、价格、示例付款提示、创始会员邀请和资格说明 |
| `/me/settings` | | 邮件提醒开关、同楼显示开关、删除账号 |

**访问规则**：
- 访客可以进入 `/roommates`、`/sublets` 及其详情页，但只能看到模糊内容；进行任何操作都会引导去注册。
- 其他页面要求已登录。
- 发起联系和发帖要求已验证且资料完整，否则跳转到缺失的那一步并说明原因。
- 封号身份只能看到封号说明页。

## 团队后台：`app/admin/`

| 路由 | 内容 |
| --- | --- |
| `/admin` | 概览：待审核和待处理的数量 |
| `/admin/admissions` | 录取材料审核：通过或拒绝 |
| `/admin/leases` | 租约审核：通过或拒绝 |
| `/admin/reports` | 举报队列：下架、警告、封号或驳回 |
| `/admin/buildings` | 楼盘和片区列表：新增或停用 |
| `/admin/founding` | 创始会员名额（已用 / 30）和领取名单 |

**访问规则**：只有 `admin` 身份能进入，其他身份显示"无权访问"（FR-010）。

## 全局元素

- **示例横幅**：出现在所有页面，可以展开为演示面板，包括身份切换、"已验证用户达到 50 人"开关、重置示例、链接到 About this demo。内部账号的面板里还有"以免费用户身份查看"开关。
- **`SampleBadge`**：标在每一处示例内容旁边。
- **示例提示**：示例邮件、示例付款、示例上传这类环节，用 toast 或行内提示告知"此处不会真实发生"。
