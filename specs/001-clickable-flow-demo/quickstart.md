# Quickstart: 验证全流程 Demo

## 前置条件

- 已安装依赖：`npm install`
- 本功能不需要 Supabase 的环境变量。

## 静态检查和单元测试

```bash
npm run lint
```

```bash
npm run typecheck
```

```bash
npm test
```

```bash
npm run build
```

**预期结果**：
- 四项全部通过。
- `npm test` 运行 `lib/rules/` 下的单元测试，覆盖 [contracts/demo-store.md](./contracts/demo-store.md) 中列出的每个规则函数，包括每一种拒绝原因。
- `build` 不出现"在 Suspense 之外访问运行时数据"的报错（见 research R2、R3）。

## 浏览器冒烟测试

先启动开发服务器（`npm run dev`），然后在手机宽度（375px）下按顺序走一遍。每一段开始前都先"重置示例"。

| # | 场景 | 预期 |
| --- | --- | --- |
| 1 | 打开任意页面 | 能看到示例横幅；展开后可以切换身份、切换 50 人开关、重置示例 |
| 2 | 访客浏览 `/roommates` 和 `/sublets`，点击联系 | 卡片模糊；被引导去注册 |
| 3 | 新用户入驻：生日填 16 岁并选在校生 → 被拦；改为成年 → 填 `x@gmail.com` → 被拒；填 `x@syr.edu` 并输入示例验证码 → 必填资料留空提交 → 逐项提示；填完 | 最终进入 `/roommates`，并且能在列表中看到自己 |
| 4 | 已录取路径：上传材料 → 切到 `admin` 审核通过 → 切回 | 标识从"审核中"变为"已录取 ✓"；后台显示"材料已删除" |
| 5 | 以 `student-free` 身份筛选并打开一份资料 | 匹配度区域模糊；能看到验证状态和注册时间 |
| 6 | 发一条请求后尝试追加；把当天的请求发满 10 条后再发 | 不能追加；第 11 条被拦下并说明每日上限 |
| 7 | 在收到的请求中分别接受、删除、拉黑 | 接受后进入聊天并看到付款提醒；删除的请求消失；拉黑后对方从所有列表中消失 |
| 8 | 在聊天中发送 "my venmo is ..." | 消息照常发出，双方都看到防骗提醒 |
| 9 | `/for-you` 免费视角：解锁 3 人，再尝试第 4 人和排名第一的人 | 第 4 人被拦下并引导到会员页；排名第一的人显示"仅会员可见" |
| 10 | 切到 `member-internal` 身份，再打开"以免费用户身份查看" | 会员视角下全部可见；打开开关后回到免费视角 |
| 11 | 把世界状态切到 `reached50`，分别以符合条件和不符合条件的身份查看会员页，并领取到名额满 | 符合条件的人看到邀请；不符合的人看到还缺哪些条件；名额满后提示已满 |
| 12 | 在会员页选择月订阅或季票 | 提示"示例：不会收取任何费用" |
| 13 | 发转租帖：缺必填项 → 被拦；填完并上传租约 → `admin` 通过 → 标记已转出 | 依次显示"租约审核中"→"租约已核验"→ 帖子从列表中消失 |
| 14 | 打开一条还没建立联系的转租帖 | 看不到精确地址；联系发帖人并被接受后，能看到 |
| 15 | 暂停资料、开启同楼显示、删除账号 | 暂停后从列表消失；同楼列表中能看到自己；删除后回到未登录状态 |
| 16 | 举报一条帖子 → `admin` 下架 | 普通用户的列表中，这条帖子消失 |
| 17 | 非管理员身份打开 `/admin` | 显示"无权访问" |
| 18 | 刷新页面，然后点重置 | 刷新后操作结果还在；重置后回到初始状态 |
| 19 | 在电脑宽度下打开 | 内容居中，可以正常操作 |

**完成标准**：19 项全部符合预期，并且 [spec.md](./spec.md) 中的 SC-001（没有死路）和 SC-004（示例标注覆盖）在走查中没有发现例外。
