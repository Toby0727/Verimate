# Verimate demo

Verified student subleasing for Syracuse University and SUNY ESF. Static demo for the UAI Fall 2026 pitch.

It's one `index.html` page, with no build step. Tailwind, fonts and MapLibre load from CDNs, and all data is hardcoded.

Add these to the address to jump to a state:
- `#agent-top`: reputation agent
- `#photo-top`: photo provenance agent
- `#dates`: date picker
